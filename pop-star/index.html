About the project

I took part in Pop Star for Global Game Jam 2024, a project set in a humorous, twisted Rock-N-Roll world. It plays with the conventions and seriousness of classic platformers through parody.

My project notes

The creative direction combines a 1950s-inspired setting with comedy and platforming. Developed for Global Game Jam 2024, it explores how a strong theme can shape a short playable experience.
