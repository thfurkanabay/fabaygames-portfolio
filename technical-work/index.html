Kids Spot the Difference · implemented in the current Unity project

Firebase & player analytics

I instrument the actual player journey, from tutorial steps and screen changes to level completion, mini-games, rewarded ads and purchase outcomes.

  • Structured events carry flow step, chapter, level, session timing and access context.
  • A bounded startup queue retains events while Firebase initialises; local counters remain available if the SDK is unavailable.
  • Background/resume events and a saved last-step checkpoint help investigate where a session stopped.

I use last-step checkpoints alongside event timing to investigate the player journey, and keep device-side validation separate from cloud reporting.

Unity · C# · Firebase Analytics

Kids Spot the Difference · implemented in the current Unity project

Rewarded ads & in-app purchases

I connect level access to rewarded advertising and a non-consumable premium purchase, with explicit states for loading, success, cancellation and failure.

  • Google Mobile Ads rewarded-ad lifecycle, readiness, retry handling and reward callbacks.
  • Unity IAP integration with store-localised prices, purchase restoration and repeat-purchase guards.
  • Premium entitlement checks before ad startup, so full-access users bypass the advertising path.
  • Parental purchase entry and privacy-options UI.

I keep ad requests, impressions, earned rewards and purchase restoration distinct in analytics, so each stage of the monetisation flow can be investigated separately.

PuzzliPop · implemented in the current Unity project

Puzzle rules & content-driven activities

I separate puzzle rules from presentation and use content assets to drive a sequence of learning activities.

  • Grid shuffling, piece swapping, connected-piece groups and hint operations in a pure C# board model.
  • Drag-and-drop input connected to the puzzle activity.
  • A level-flow coordinator for introduction, puzzle, question, mini-game and reward steps.
  • ScriptableObject definitions for chapters, levels, difficulty and songs.
  • Chapter progress, stars, badges and song unlocking in versioned save data.
  • A service bridge for Firebase Analytics, rewarded ads and full-game purchases.

These notes describe the current development project; the store release can be an earlier version.
